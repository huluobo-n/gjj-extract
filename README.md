# 公积金装修 / 物业费提取额度测算（gjj-extract）

静态单页工具：默认**郑州**，对照南京 / 杭州 / 济南 / 上海。场景可切换「装修提取」「物业费提取」。

- 计划域名：`gjj.hpn6.com`
- 建议仓库名：`gjj-extract`
- 形态：纯 HTML/CSS/JS，无后端
- 数据核对日期：**2026-11-06**（Asia/Shanghai）
- **非任何住房公积金管理中心官方产品**

## 本地预览

```bash
cd /workspace/gjj-extract
python3 -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777/
```

或直接打开 `index.html`（已内嵌城市数据快照；HTTP 下优先加载 `data/cities.json`）。

## 醒目免责（产品内已置顶）

1. **以当地公积金中心为准**，结果仅供参考，不冒充官方。  
2. 实际可提受**账户余额**、逾期贷款、材料核验等限制。  
3. 一城一策，禁止把郑州分档当成全国统一标准。

## 验证计量

- 「开始测算」→ `localStorage` 键 `gjj_extract_calc_count_v1`  
- 「帮算」留联 → `gjj_extract_leads_v1`  
- 页顶显示次数；成功线文案：**测算 ≥30 或 留联 ≥5**  
- 纯静态计数在用户各自浏览器；全站 UV 需另接分析。

## 数据缺口 / 风险

1. **郑州装修通知**：官方中心全文页本轮以媒体/门户转述为主（一财、中原网），额度与条件多方一致；建议落地后补链中心正式 HTML/PDF。  
2. **上海**：国家条例已放开场景，本地额度细则未核到 → UI 标待核对、不可算。  
3. **济南装修**：仅核到物业费等提取，装修额度待核对。  
4. 杭州物业费政策报道早于 2026-09-20 条例施行日（2026-05 开通线上），后续是否改口径需复查。  
5. 郑州物业费「是否必须 ≤ 实付账单」官方分档为政策上限；本页在有账单输入时取 min(档位, 实付) 便于用户对照，已在结果说明中注明。  
6. 留联仅 localStorage，无服务端汇总。
